# CHOG SOULS Roadmap

## Phase 1 — MVP (complete)

Core product shipped for CHOGATHON:

- [x] Landing page
- [x] Demo Soul (Chog #1777, "Giga")
- [x] Dark Monad-inspired UI
- [x] Trait display from NFT metadata
- [x] Soul stats (Courage, Loyalty, Intelligence, Greed)
- [x] Browser localStorage persistence
- [x] AI chat powered by Alibaba Qwen
- [x] Daily quest with 4-choice moral dilemmas
- [x] Arena battles with stat-weighted combat
- [x] Memory timeline
- [x] Wallet connector (MetaMask / EIP-1193)
- [x] Mobile layout

## Phase 2 — Real Chog Integration (complete)

- [x] Read owned Chog NFTs from Monad Mainnet
- [x] Fetch real token metadata via on-chain RPC
- [x] Decode actual traits to Soul stat weights
- [x] One persistent Soul per Chog (bound by token ID)
- [x] Wallet ownership verification via signed message
- [x] 6 demo Chogs for walletless testing

## Phase 3 — AI Memory System (complete)

- [x] Importance scoring for each memory (0–100)
- [x] Automatic memory summarization at threshold
- [x] Context retrieval: most relevant memories injected into AI prompt
- [x] Structured stat updates returned from AI
- [x] Memory fade for low-importance entries

## Phase 4 — Social Features (complete)

- [x] 9 rival Souls with unique stats, archetypes, and avatars
- [x] Rival profile pages (click any rival on the leaderboard)
- [x] Rival taunts before battles and reactions after
- [x] Leaderboard with live player rank
- [x] Share card: one-click PNG export for Twitter

## Phase 5 — Polish (complete)

- [x] Sound effects: level-up, evolution, arena win/lose, chat reply
- [x] Level-up sparkle animation banner
- [x] Archetype evolution animation
- [x] Daily streak system (escalating rewards through day 7)
- [x] 8 achievements with live progress tracking
- [x] $CHOG token balance reader with XP bonus tiers
- [x] Onboarding walkthrough for first-time visitors
- [x] IPFS image proxy with local cache

## Phase 6 — Deployment and Community (upcoming)
