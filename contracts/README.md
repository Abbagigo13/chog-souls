# CHOG SOULS Contracts

The MVP does NOT require a custom smart contract.

The first blockchain functionality will be read-only:

- Detect Chog NFT ownership
- Read Chog token ID
- Read Chog metadata
- Read Chog traits
- Use traits to generate the Soul

Later, if necessary, contracts can be added for:

- Soul achievements
- Soul evolution
- On-chain badges
- Special Chog experiences

## Important

Never ask the user for:

- Seed phrase
- Private key
- Wallet password

Before integrating the real Chog NFT, verify the official:

- Chog NFT contract address
- Monad chain ID
- RPC endpoint
- Metadata structure

Do not hard-code unverified blockchain addresses.
