# CHOG SOULS Backend

FastAPI backend for CHOG SOULS.

The backend handles:

- Soul data
- AI conversation endpoint
- Memory creation
- Decisions
- Stat changes
- Arena battles

The current version intentionally uses in-memory data.

No paid database is required.

No paid API is required.
